# Atria-ERP Relational · Pàgina 06

Aquesta pàgina forma part del projecte **Atria-ERP Relational**, una aplicació web dissenyada per mostrar el compliment de les 12+1 regles de Codd en el model de dades relacional usat per Atria-ERP.

## Contingut

- `qpag06.html` – Pàgina HTML amb la infografia de les regles de Codd.
- `regles.js` – Script dinàmic per mostrar el contingut de cada regla (en desenvolupament).
- `menu.html` – Menú de navegació (es carrega dinàmicament).
- Imatges: `img/llibreta.png`, `img/logo.png`, `img/pag06_bn.png`.

## Ús

1. Obri `qpag06.html` en qualsevol navegador modern.
2. El menú i els textos es carreguen dinàmicament.
3. Pots navegar per les regles fent clic sobre cada una.

## Requisits

- Navegador compatible amb JavaScript.
- Connexió local als arxius indicats.

## Estat

Projecte en desenvolupament. El fitxer `regles.js` s'ha de completar amb el contingut detallat de cada regla.

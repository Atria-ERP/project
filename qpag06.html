El cumplimiento de las reglas de Codd certificant un modelo relacional

Atria-ERP Relacional funciona bajo un modelo de petición–respuesta. Cada acción es independiente y autónoma, ejecutada a partir de las estructuras y valores. No mantiene sesiones activas de usuario ni estado en memoria para gestionar el contexto.

0. Fundación

Un sistema que pretende ser relacional debe gestionar sus datos exclusivamente mediante sus capacidades relacionales.

Es decir, si afirma ser relacional, debe utilizar únicamente el modelo relacional para representar y operar con los datos. No vale usar trucos o mecanismos ajenos al modelo.

Atria-ERP cumple plenamente esta regla. No depende de procesos ocultos, código encapsulado ni lógica externa. Todo el sistema se construye sobre flujos y estructuras declarativas que definen entidades, relaciones y documentos.
